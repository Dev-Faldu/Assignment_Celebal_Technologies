Interactive Guide: ML Deployment & SQL Fundamentals
This project is a self-contained, single-page web application designed to be an educational tool. It transforms a technical guide on machine learning deployment and SQL basics into a fully interactive and user-friendly experience. The application is built with vanilla HTML, Tailwind CSS, and JavaScript, and runs entirely in the browser with no setup required.

Features
Dual-Topic Interface: A clean, tabbed navigation system allows users to seamlessly switch between the "ML with Streamlit" and "SQL Fundamentals" sections.

Interactive ML Simulator: A hands-on module that simulates a real Streamlit application for Iris flower species prediction. Users can:

Adjust sliders to input features (sepal length, petal width, etc.).

Receive an instant, simulated prediction from the model.

See visual feedback with an image of the predicted flower species.

SQL Command Reference: An easy-to-navigate, accordion-style reference for core SQL commands, including:

DDL: CREATE, ALTER, DROP, TRUNCATE

DML: INSERT, UPDATE, DELETE

TCL: COMMIT, ROLLBACK, SAVEPOINT

Responsive Design: The application is fully responsive and optimized for a seamless experience on desktops, tablets, and mobile devices.

Zero Installation: As a single HTML file, the guide requires no installation, dependencies, or backend. Just open it in a browser to get started.

Technologies Used
HTML5: For the core structure and content.

Tailwind CSS: For a modern, responsive, and utility-first styling approach.

Vanilla JavaScript: For all interactivity, including the navigation, ML simulator logic, and accordion functionality.

How to Use
Simply download the ml_sql_interactive_guide.html file and open it in any modern web browser (like Chrome, Firefox, Safari, or Edge).

This project was created to demonstrate how static technical documentation can be transformed into an engaging and effective learning tool through thoughtful UI/UX design and interactivity.
